# Markdown to HTML Converter

A beautiful, sleek, and modern web application that converts Markdown text into HTML in real-time. It features a premium dark-mode aesthetic with glassmorphism design elements.

## Features

- **Live Preview**: See your Markdown rendered as HTML instantly as you type.
- **Raw HTML Output**: Get the raw, copyable HTML code alongside the preview.
- **Premium Design**: Built with a sleek dark theme, glass-like panels, and smooth micro-interactions.
- **Responsive Layout**: Adapts perfectly to both large desktop monitors and smaller screens.
- **Zero Dependencies**: Pure HTML, CSS (Vanilla), and JavaScript for maximum performance and flexibility. (Uses Google Fonts for typography).

## Getting Started

1. Clone or download this repository.
2. Open `markDown.html` in your favorite web browser.
3. Start typing Markdown in the input panel and watch it convert instantly!

## Supported Markdown

The converter currently supports the following standard Markdown features:
- Headings (`#`, `##`, `###`)
- Bold (`**text**` or `__text__`)
- Italics (`*text*` or `_text_`)
- Links (`[title](url)`)
- Images (`![alt text](image url)`)
- Blockquotes (`> quote`)

## Technologies Used

- HTML5
- CSS3 (Vanilla, CSS Variables, Flexbox)
- JavaScript (ES6, Regex)
